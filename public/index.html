Como Configurar o Envio para o Telegram

1

Criar o Bot no Telegram

Abra o Telegram e pesquise por @BotFather. Envie o comando /newbot, escolha um nome e um username terminado em bot (ex: meu_audiolivro_bot). O BotFather fornecerá um Token de API (ex: 7123456789:AAH...). Copie e cole na seção de configurações.

2

Pegar o seu Chat ID ou ID do Canal

Para enviar no seu privado: Inicie uma conversa com o seu bot recém-criado (clique em /start). Para descobrir seu ID, chame o bot @userinfobot no Telegram e copie o Id numérico.

Para enviar para um Canal ou Grupo: Adicione o seu bot como Administrador do canal (com permissão de postar mensagens). O Chat ID do canal público é o seu username (ex: @meucanal) ou o ID numérico negativo para canais privados (ex: -100192837465).

3

Pasta do Google Drive

A pasta já vem pré-configurada com o link fornecido. Ela precisa estar com permissão "Qualquer pessoa com o link pode visualizar" no Drive. Clique em "Escanear Pasta" para listar os 12 capítulos em MP3 e clique em "Enviar Selecionados".

Limite do Telegram Bot API: Cada arquivo pode ter até 50 MB. Os áudios desta pasta têm em média 15 a 20 MB, portanto estão 100% dentro do limite!
